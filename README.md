# Credit Operations Projects

Two Excel practice projects that mirror the day-to-day work of a **Credit Operations / Financial Analyst** role: extracting data from structured-finance reports, quality-checking it, and maintaining company and peer credit metrics.

> **All data in these projects is fictional.** The companies, the securitisation and every number were created for practice. Nothing here is a real transaction or a real company's financials.

| # | Project | Tools | What it shows |
|---|---------|-------|---------------|
| 1 | [Trustee Report Data Extraction & QC Tracker](Project1_Trustee_Report_QC_README.md) | Excel (formulas, conditional formatting) | Data extraction into a pre-defined template, reconciliation, 12 automated quality-control checks, error logging |
| 2 | [Company & Peer Credit Metrics Dashboard](Project2_Peer_Credit_Metrics_README.md) | Excel (SUMIFS, MEDIAN, RANK, charts) | Leverage, coverage and margin metrics, peer median and average, trend tables and charts |

## Skills demonstrated

- Financial data handling and reconciliation
- Quality-control checks and error logging
- Credit metrics: Debt/EBITDA, Net debt/EBITDA, EBITDA/Interest, margins
- Structured-finance terms: pool balance, charge-offs, delinquency buckets, note classes, coupon, overcollateralisation (OC)
- Clear documentation of assumptions and workbook design
